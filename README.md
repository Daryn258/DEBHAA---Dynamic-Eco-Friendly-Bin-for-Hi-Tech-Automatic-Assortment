DEBHAA : Dynamic Eco-Friendly Bin for Hi-Tech Automatic Assortment

DEBHAA is a smart, automated waste segregation system that detects and classifies wet, dry, and metal waste using embedded electronics and sensors. This IoT-based prototype aims to promote sustainability by improving waste sorting at the source.

🧠 Features
🔍 Automatic detection of waste type
💧 Moisture sensor for wet waste
🔩 Inductive sensor for metal detection
📟 Real-time feedback via LED display
⚙️ Servo-controlled flap mechanism for precise sorting

🔧 Components Used
Arduino Uno
IR Proximity Sensors
Moisture Sensor
Inductive Metal Sensor
Servo Motors
LED Display
Jumper wires, breadboard, and other supporting components

🛠️ How It Works
Waste is inserted into the bin.
Sensors detect proximity and classify the waste:
Wet Waste: Detected by the moisture sensor
Metal Waste: Detected by the inductive sensor
Dry Waste: If neither moisture nor metal is detected
The servo motor directs waste into the correct bin.
LED display shows real-time classification and actions.
